# Region-Specific VPS Shopping Notes — UK / SG / TR / JP

按地区找便宜 VPS 时的已验证商家与价格锚点。价格是当时的实测快照，报价前重新打开链接核价；推荐前照 SKILL.md 走时效+负面+可购性验证。

## 验证方法（地区选品通用）

1. DDG 站内搜：`site:lowendtalk.com <city/country> VPS offer 2026` 逐地区跑（一次 4 个 query 并发）。
2. LET 帖必须区分 **Offers（促销）vs WTB（求购）**——标题带 "Looking for"/"WTB" 的是求购帖，不能当促销收（踩过：DataCamp 土耳其实为求购帖）。
3. 二手聚合站（hosting.gallery 等）价格与官网矛盾时以官网为准，聚合价未核实不采信。
4. 促销码限定数量/循环属性/最低月付必须原样转述（"50 个码""循环折""12 个月付起"是购买决策的一部分）。

## 🇸🇬🇯🇵 新加坡 / 东京（亚太高性价比首选）

- **OrangeVPS** BASIC-AP 系列（SG/HK/Tokyo 同配置同价）：常价 $6/mo（1C2G/25G NVMe/2TB/1Gbps）。
- 大促（国庆等）出 60% 循环折码（限量 50 个，最低 12 月付）→ ~$23/年；双倍 RAM 活动日再翻倍。官方暂无全局常设码，等下一轮活动。
- 交叉验证路数：LET 促销帖 + nodeseek 实际成交/续费帖（搜 `OrangeVPS BASIC-AP`）双源。
- 日本备选：SpeedyPage Tokyo（7950X/DDR5，$14.99/mo 起，贵）；JUST.HOSTING 东京（35% 循环折 ~$5.26/mo，活动窗口期有效，该商家有误封号投诉史，只试水别年付）。

## 🇬🇧 英国

- 英国机房普遍贵，地板价在 **VM6**（伦敦）：~£1.75/mo 1C1G/20G NVMe/2TB，9950X，反 DDoS；LET 促销帖长期有效。

## 🇹🇷 土耳其

- 无像样的低价选项：老牌 Hostiger 官网自报 ~$15/mo 起；LET 无近期促销（有也多为求购帖）。用户要土耳其 IP 时直接说明"没有便宜的"，别硬凑。

## 用户约束

- Parker 预算极紧（年付几十刀是上限），报价时把"循环续费价"放第一位，首月价只能当试水标注。
