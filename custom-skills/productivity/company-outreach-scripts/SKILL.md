# 企业客户开发话术工作流

## 触发条件
用户（易盘点销售，妈妈）发来一家公司名，要求"查查这家公司/怎么沟通/电话话术/发邮件"。

## 标准流程
1. **查公司**：web_search 两轮并行——「公司名 主营业务」+「公司名 联系方式 官网 电话」
2. **汇总**：业务板块 / 客户群 / 规模 / 融资或资质（专精特新、高新、独角兽、IPO）/ 联系方式（电话、邮箱、地址、官网）
3. **判断合作价值**（决定话术方向）：
   - **先避雷**：扫企查查风险栏——股权冻结/被限高/欠税公告/债权挂牌转让，占两条=债务危机，★划掉不接触不写话术；许可资质被依法注销（安全生产许可等）/公告停产转型=经营不确定，先核实现状再投入
   - **查背景**：新设公司（成立1-2年）必查母公司/控股方（融资、国资背景、关联企业）——自身资料少时母公司实力决定星级与话术对象
   - **直销型**（制造/硬件/设备公司）：自身固定资产多 → 卖产品给行政/财务
   - **渠道型**（ERP/安全/数字化/代运营服务商）：客户群与易盘点重叠 → 谈客户互推+渠道分润
   - **两者兼有**：先直销后渠道
   - **非直客 3 型**（2026-09 单查总结）：①**区域渠道载体**（大厂区域公司，如唐山致远互联=致远OA唐山载体）→ 谈"OA客户+资产模块加签分润"，别按直客卖SaaS，决策人就是老板本人；②**跳板型**（营销代运营/文旅轻资产，如云知网络、双途文旅）→ 自身设备需求弱只值 1~2 星，真价值是手里的政企/文旅客户关系 → 主打"客户互荐+居间分成"；③**互补硬件型**（定位/物联硬件商，如翰东技术 UWB：工具管控管位置，易盘点管台账维保）→ "互补不打架+客户互荐+其自产设备也用易盘点管理"。县域小微制造（五金/建材）=2星以下：低价版+免费试用钩子群发触达，不主动花时间，有涉诉记录的坚持预付款
   - **央企/国企画像三件套**（单查云南建投钢结构总结）：①集团旗下公司是主目标——注册资本/员工数/基地规模决定星级（≥4星），审计合规是首选钩子；②查控股方持股比例确认国企身份，档案写明持股关系；③钩子组合=「集团审计账实一致 + 多基地扫码盘点 + 特种设备（如机械停车设备）维保到期提醒」，切入部门=设备管理部/机电部/审计部，决策链长需案例养单；④子公司名可能用旧称（搜「云南建工钢结构」实际是已更名的云南建投钢结构），搜不到先查是否更名，档案用现名+正文注明曾用名
4. **写话术**：按沟通对象分层（见下）

## 话术分层模板（核心）
- **跟行政聊**：设备管理痛点——设备在哪/谁在用/借还乱。制造业→产线设备/SMT/样机借用；IT软件公司→高配电脑/测试机/离职交接；外包公司→员工流动大、电脑收发；网络/硬件公司→路由器交换机+多地分支
- **跟财务聊**：账实相符、审计、融资尽调、折旧、金蝶用友对接。重点：拟上市公司→"IPO资产合规/尽调加分"
- **跟老板聊**：先夸成就（客户案例/资质/融资），再谈价值。技术型老板→"让您专心研发"+尽调加分；销售型老板→"客户资源共享、零成本分润"
- **邮件**：标题带公司名+方案关键词，正文=夸赞+痛点+4点产品价值+免费试用钩子+签名（名字/电话占位符XX提醒用户替换）

## 联系方式查找渠道（按优先级）
1. 官网"联系我们"页（最准）
2. 企查查/天眼查移动页（web_extract 可读，有电话/邮箱）
3. 招聘网站（BOSS/猎聘/校招信息，常有座机+HR联系人）
4. B2B黄页（八方资源/启明白，常有销售手机号）
5. 官网失效时：ICP备案查询找域名，或公司新闻里的联系人姓名
7. 官网"联系我们"页常见「联系人：XX 手机：13x-xxxx-xxxx（微信同号）」直接可用；第三方企业详情聚合站（qske 等）有时公开法人手机+邮箱+官网域名

## 注意
- 电话话术按法人姓氏定制称呼（赖总/王总），一家一个叫法
- 话术里"XX"是用户名字/电话占位符，交付时提醒替换
- 提醒用户：邮件发完隔2-3天电话跟进
- 用户偏好：要完整可直接复制粘贴的版本，先给最推荐的，再问是否要变体
- 查公司时注意风险信息（裁判文书/开庭公告）要如实提醒
- 重复收到同一家公司名 = 要完整资料重发：从知识库 md / 已有资料直接取，按固定七段文字版完整再发一遍；别只回"查过"或丢个文件路径
- 用户连发多家公司名（或打断上一家调研、补发新的）= 一起查完打包交付：一条消息里 ①②③ 分节、每节给完整七段资料，跟进备注合并成一节收尾；别一家一条刷屏，也別漏掉被打断的那家
- 用户点名"电话完整话术/邮件话术再发一份" = 当场贴完整独立文本（电话版含异议处理段），别指路文件或只报已有过
- 批量名单用户点名"不要千篇一律/要针对每家公司都写一份" = 类型模板话术被否，必须逐家手写定制（技术见 batch-research-execution.md「逐家定制话术批量生产」节）；哪怕全名单同行业（如清一色IT公司），也要按细分方向拆出不同钩子
- 用户发**公司名单文件**（CRM 导出/客户池）而非探迹名单时同样按逐家定制流程走：先解析文件结构（可能无表头、单列竖排、以 `[名单客户]` 标签行+公司名+融资/岗位备注的分块格式，按标签行分段读，别按固定列读），分层标记（S1/S3/S5 等）保留进 Excel 单独一列；若用户补充要求「标注企业性质」，加企业性质列（央企/国企/私企），性质列做颜色区分（央企红/国企橙）便于妈妈扫优先级
- **企业性质判定必须两遍**：关键词规则（中字头/集团/国资）跑完后，对结果里的"私企"再人工扫一遍集团系子公司——「云南建工钢结构」「碧水源」这类集团子公司名不含关键词会错标私企（正确=建投系国企/中交系入主）；查性质/注册资本/股东时从 web_search 摘要拼（企查查/爱企查详情页是 JS 渲染，web_extract 只回脚本代码）；搜不到的老名单公司先查是否更名（旧称≠现名），档案用现名+正文注明曾用名
