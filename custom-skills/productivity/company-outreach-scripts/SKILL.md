# 企业客户开发话术工作流

## 触发条件
用户（易盘点销售，妈妈）发来一家公司名，要求"查查这家公司/怎么沟通/电话话术/发邮件"。

## 标准流程
1. **查公司**：web_search 两轮并行——「公司名 主营业务」+「公司名 联系方式 官网 电话」
2. **汇总**：业务板块 / 客户群 / 规模 / 融资或资质（专精特新、高新、独角兽、IPO）/ 联系方式（电话、邮箱、地址、官网）
3. **判断合作价值**（决定话术方向）：
   - **直销型**（制造/硬件/设备公司）：自身固定资产多 → 卖产品给行政/财务
   - **渠道型**（ERP/安全/数字化/代运营服务商）：客户群与易盘点重叠 → 谈客户互推+渠道分润
   - **两者兼有**：先直销后渠道
4. **写话术**：按沟通对象分层（见下）

## 话术分层模板（核心）
- **跟行政聊**：设备管理痛点——设备在哪/谁在用/借还乱。制造业→产线设备/SMT/样机借用；IT软件公司→高配电脑/测试机/离职交接；外包公司→员工流动大、电脑收发；网络/硬件公司→路由器交换机+多地分支
- **跟财务聊**：账实相符、审计、融资尽调、折旧、金蝶用友对接。重点：拟上市公司→"IPO资产合规/尽调加分"
- **跟老板聊**：先夸成就（客户案例/资质/融资），再谈价值。技术型老板→"让您专心研发"+尽调加分；销售型老板→"客户资源共享、零成本分润"
- **邮件**：标题带公司名+方案关键词，正文=夸赞+痛点+4点产品价值+免费试用钩子+签名（名字/电话占位符XX提醒用户替换）

## 联系方式查找渠道（按优先级）
1. 官网"联系我们"页（最准）
2. 企查查/天眼查移动页（web_extract 可读，有电话/邮箱）
3. 招聘网站（BOSS/猎聘/校招信息，常有座机+HR联系人）
4. B2B黄页（八方资源/启明白，常有销售手机号）
5. 官网失效时：ICP备案查询找域名，或公司新闻里的联系人姓名

## 注意
- 话术里"XX"是用户名字/电话占位符，交付时提醒替换
- 提醒用户：邮件发完隔2-3天电话跟进
- 用户偏好：要完整可直接复制粘贴的版本，先给最推荐的，再问是否要变体
- 查公司时注意风险信息（裁判文书/开庭公告）要如实提醒
