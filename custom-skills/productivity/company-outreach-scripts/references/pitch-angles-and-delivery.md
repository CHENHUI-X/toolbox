# 交付偏好 + 高风险规则 + 渠道细分角度

> 来源：2026-08 易盘点陌拜系列会话（单家调研：太极华保/天健软件/历康/众源/西部泰力/新才网络；批量：185家名单）。

## 交付偏好（妈妈，微信场景）

1. **单家公司调研 → 纯文字直接发微信**（妈妈原话："查完了文字形式发给我"）。
   固定文字版顺序：①公司概况（成立/法人/资本/资质/主营/客户）→ ②合作价值星级+理由（★~★★★★★，注明扣分点）→ ③联系方式（官网/电话/邮箱/地址/关键人）→ ④电话话术（可直接照着念的完整版）→ ⑤微信验证语2条+通过后开场白 → ⑥邮件模板 → ⑦跟进备注。
   不要只发文件/路径；文字才是妈妈要的交付物，文件（知识库 md）是附带存档。
2. **批量名单任务 → 后台跑完填 Excel 再 MEDIA 发文件**（妈妈原话："你后台弄表格就行啦"）。中途别频繁汇报进度，只报开始/完成。

## 高风险客户规则

出现以下任一信号 → 星级旁标"⚠️高风险"，话术/备注写死收款安全条款：
- 财务恶化：连年亏损（如银之杰4连亏，2025预计亏1.1-1.4亿）、净利润同比暴跌（如西部泰力-85%）
- 诉讼缠身：裁判文书/立案信息几十件（西部泰力 34文书+39立案）
- 注册资本过小/小微且无亮点
标准写法："只谈免费试用和小单、坚持预付款、绝不赊账"，放在话术前和跟进备注里都提醒。

## 话术分寸规则（涉敏行业 + 复制信号）

- **军工/涉密背景企业**（军事装备模拟、国防配套等）：话术只夸资质（高企/专精特新/独角兽）与技术板块，不问具体军方项目与装备型号，不点名军队客户；对接走行政/采购口，别碰业务保密面。同分寸适用于司法公安口客户：只泛泛夸"行业标杆"，别追问案例细节。
- **法人关联企业矩阵 = 复制信号**：调研时必看老板名下控制几家关联企业——控制多家（5家以上）= 谈成一家可复制到关联公司，跟进备注里注明"可复制对象"（关联公司名）；多地子公司/分公司同理，主打"多基地资产一张表"角度。

## 渠道型客户细分角度（打包进对方方案的行业痛点库）

渠道型 = 对方客户群与易盘点目标（资产密集/政企）重叠，把易盘点作为对方方案的一个模块，渠道分润。按对方行业换切入痛点：

| 对方类型 | 实例 | 切入话术角度 |
|---|---|---|
| 政企方案打包线（给公安/医院/政企做智慧方案的软件商） | 太极华保（保险IT）、天健软件（智慧出入境/医疗）、众源科技（智慧司法） | "打包资产/设备管理模块+监管合规（审计/国资清查报告一键出）+渠道分润"；保险类加"监管对IT资产合规要求" |
| 医疗信息化线（医疗软件商/医疗大数据） | 天健软件、柯林布瑞 | "医疗设备资产管理"：CT/彩超/监护仪台账、维保、计量检定；医疗设备贵、监管严、需求明确 |
| 档案互补线（档案数字化公司） | 历康信息 | "档案管纸、我们管设备"，明确互补不抢对方档案主业（那是人家饭碗，别碰） |
| 定位硬件厂商线（北斗/定位硬件商） | 深圳北斗通信 | "定位硬件+资产台账"软硬结合方案：卖给电力/石油/铁路等资产大户（铁塔/管道既要管位置又要管台账） |
| 职教/高校线 | 优优汇联 | 切"实训设备/机房设备管理"细分，别碰通用高校资产管理系统红海 |
| 供热/公用事业线 | 辽宁北软 | 客户（热力公司）全是重资产（锅炉/换热站/管网），北软产品线"收费+经营+诉求"正好缺资产模块 |
| 共同客户破冰 | 蜀云物连+华润雪花 | "咱俩算半个同事——我们都服务雪花"；分寸：只提服务层面不透露金额细节、别让对手觉得你要撬他客户 |
| 大厂区域渠道公司（上市公司在本地设的渠道载体） | 唐山致远互联（致远互联688369唐山核心载体） | 不按直客套路卖SaaS：谈「客户上OA常问资产能不能管」的项目加签+渠道分润；这类公司决策人就是负责人本人，直接找老板效率最高；别把母公司当竞品——OA管流程、易盘点管资产，互补关系 |
| 营销代运营公司（短视频/品牌代运营，服务政企文旅口） | 云知网络（服务省文旅厅/市文广旅局） | 自身轻资产没需求，重头是它的政企客户关系：谈「文旅口客户（景区/场馆/博物馆）有演艺设备、展陈设施管理需求，互相引荐+居间分成」，顺带卖它自己的电脑/拍摄设备台账 |
| 工业软件互补线（QMS/质量管理软件商） | 希维科技（汽车/半导体/3C 全生命周期质量管理平台+统计分析国产替代工具） | "QMS管质量数据、易盘点管资产实物"——客户群完全重合（先进制造都是资产刚需户）且需求互补不重叠；对方的现场实施团队是天然引流渠道：实施进场时顺带了解客户资产盘点需求，双向互荐+项目加签分成 |

## 其他可复用要点

- 硬件厂商类（星联云科/飞鱼星/持恒/中科光智/西部泰力）：主打"样机/测试设备/产线设备台账+维保+防丢失防闲置"，激将法弹药"卖网络管理设备的自己别用Excel"
- IPO/并购期公司（瀚博/数盾/中科星图系）：主打"一次盘点交付审计可用台账"
- IDC/数据中心（世纪互联/普洛斯）：机柜/UPS/制冷设备维保是运营刚需，直接找设施管理部
- 竞品（如上海久其软件，做资产管理软件）→ 标"竞品别推"，不写话术，提示以行业交流名义接触或跳过

## 垫底档速判（不用单独深查，群发通用话术即可）
- C端在线教育/兴趣课（中老年兴趣课这类）：电脑+摄像头就是全部资产，客户是个人，无B端价值
- 露营地/文旅小运营方：场地是租的、设备是可移动的帐篷天幕，固定资产基数小且现金流紧
- 县域五金/建材/贸易小微：设备需求真实但付费能力弱——低价版+免费试用钩子，群发触达，谁回复谁有戏
- 判断口诀：客户是C端、场地是租的、注册资本百万级——三条中两条即垫底，★以下，文字交付也压到简版（话术只给一条简版）
