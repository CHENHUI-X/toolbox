# 批量深挖执行（Batch Research Execution）

> 场景：用户（妈妈）发来探迹 Excel 名单并说"A档都查/都查了把"，要求把几十上百家公司全部调研，资料+话术填回名单 Excel。
> 实例：2026-08 深挖 185 家（A37 完整话术+邮件、B48 精简、C100 基础），全部填回名单 Excel 并 MEDIA 发回微信。

## 执行方式（踩坑后的可靠路径）

1. **别用 delegate_task 每任务查 6 家**——600s 超时，两次全挂（子代理模型处理慢 + DDG 不稳定）。每任务 ≤3 家才稳，或干脆不用子代理、自己用 execute_code。
2. **推荐：execute_code 自己批量抓**：
   - `from hermes_tools import web_search, web_extract` 循环。⚠️ hermes_tools 只能在 execute_code 里 import（terminal 的 python 没有该模块），抓取脚本一律走 execute_code；Excel 读写两边都行（terminal 缺 openpyxl 时先 `pip install openpyxl -q`）
   - web_search 每家 1 次，24 家/批 ≈ 70~190s 可行
   - **DDG 限流**（报 `DDGSException: No results found` 或越来越慢）时：改用 `web_extract` 抓百度百科，一次传 5 个 URL（`https://baike.baidu.com/item/{urllib.parse.quote(name)}`），25 家 ≈ 50s，明显更快更稳
   - 每批结果立即写 JSON 文件（`/root/.hermes/cache/documents/<批次>/batchN.json`），防 execute_code 超时被杀丢数据
3. **⚠️ 百度百科错位陷阱（必须处理）**：词条不存在的 URL 会返回其他内容/搜索页，返回顺序 ≠ 请求顺序。**必须从内容里提取 `^#\s*(.+)$` 标题行，建立 title→content 映射，再按公司名匹配**——否则资料张冠李戴（实例：44 条内容里 12 家错位）。
4. **⚠️ openpyxl 写入坑**：百科原文含控制字符（\b 等）→ `IllegalCharacterError`。写入 Excel 前必须 `re.sub(r'[\x00-\x08\x0b\x0c\x0e-\x1f\x7f]', '', text)`。
5. **信息有限的兜底**：搜不到的小微公司，经营内容填「公开信息有限，建议电话核实」，星级 ★☆~★★，标注"暂缓"，不要硬编资料。
6. **C 档也能捞到遗珠**：批量后人工扫一遍，制造类/专精特新/有融资的升 B（实例：久雅金融IT、本手OPPO系外包、商达政采分销、富迪IATF制造、嘉萌专精特新制造、成生鸿泉物联旗下）。
7. **档内避雷**：批量分级时对 A/B 档快速扫企查查风险栏——股权冻结/被限高/欠税公告/债权挂牌转让占两条 = 标"债务危机暂缓"或划掉，别给死企业写话术。

## 填回 Excel 的列布局（妈妈的主工具是名单 Excel，不是散文件）

- ⚠️ **列布局每次不同，先读表头确认实际列号再填**——新名单可能自带 法人/电话/跟进记录/分级 等列，话术列从最后一个已用列往后加；套用上一批的固定列号会覆盖原有数据

- 列 4「经营内容」：`【定位】【概况】【资产特征】【合作价值】星级【联系方式】【关键人】【切入角度】【风险】` 八段
- 列 9「电话话术」、列 10「微信验证语+开场白」、列 11「邮件模板」（A 档全给，B/C 精简）
- 话术按客户类型套模板：IDC型 / 硬件研发制造型 / 检测服务型（检测仪器台账+计量校准记录管理）/ 物联网平台型（自有设备+平台资产+客户设备打包）/ 央企国企型 / 软件科技型 / IPO并购型 / 竞品型（竞品只标"别推"不写话术）。类型判定按公司名关键词+查到的主业路由；大厂分公司留A档但话术须注明「采购权在总部，先核实本地决策权」
- 完成后验证统计（分级数/经营内容数/话术数），MEDIA 发回 Excel

## 第二批实例（2026-09-08 杭州为主名单）

- 400 家 → 划掉 21（运营商区县网点/广电营业部/邮电代办点/事务所分所）→ 保留 379：A55 / B273 / C51。杭州/上海名单里半导体、机器人、光电、检测仪器类比上批多，A 档占比明显高
- **百科命中率低时别死磕单家**：55 家 A 档首轮百科只中 17 → 立即换 web_search（每家 1 次「公司名 公司」+0.8s 间隔，分两轮跑，命中约 13/34）→ 剩余小微在 Excel 里填「公开信息有限，建议电话核实」，不要为单家反复重试
- A 档批量填的话术按类型路由（硬件研发型/检测型/物联型/央企型），话术列全部填通用骨架（夸→痛点→扫码即盘→免费试用→加微信），央企系另加「采购权在总部」提示
- 大厂分公司（中兴技术服务/长虹佳华/TCL/亚信/中船数字等）留 A 档但定位是「总部采购，本地无决策权」；母公司融资背景（如形弈科技=润芯微全资子公司，母公司近4亿B+轮）是价值信号，查公司时顺藤查母公司

## 批量调研的交付习惯（用户偏好）

- 妈妈明确说过"你后台弄表格就行啦"——批量任务后台跑完再汇报，不要中途频繁打扰
- 完整交付 = 名单 Excel（资料+话术填好） + 必要时的速查卡 zip / 速查总表
- 深挖的公司资料同时存知识库 `易盘点客户/` 目录（每家一个 md）
