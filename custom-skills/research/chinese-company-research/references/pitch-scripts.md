# 商务开发话术模板（查完公司后按类型定制）

适用：妈妈/老板做易盘点（固定资产管理SaaS）销售，拿到公司名→查完→要话术。所有话术中的 XX / 电话 / 邮箱 为占位符，交付前提醒用户替换。

## 1. 电话话术骨架（通用）

```
第一步：打总机（别打400售后！）
> 您好，麻烦转一下行政部/综合管理部，谢谢～
（被问啥事）> 我是易盘点的小X，做资产管理软件的，想找行政负责人聊两句～

第二步：找到负责人后
开场：> 您好，我是易盘点的小X，做固定资产管理系统的。知道贵司[具体成就：客户名/项目/榜单]，非常厉害👍 冒昧打这个电话，想聊聊[贵司资产管理/合作机会]这块～
切入：> [按类型痛点]……我们易盘点就是管这个的：
  ① AI扫码盘点：设备贴码，手机一扫全清楚
  ② 员工自助：借还扫码自办，离职一键交接
  ③ 台账/保养提醒：设备状态、维保周期自动记录
被问价格：> 按规模定，可以先免费试用，好用再谈。
被说不需要：> 理解～方便加个微信吗？我发份资料您存着，以后有需要随时找我。
收尾：> 那先加微信发资料，以后常联系。
```

## 2. 各类型切入角度 + 应答点

### 制造/硬件厂（懿美莱、瑞意博、智联信通、珍圭谷）
- 痛点：SMT贴片机/产线设备百万级、台账乱、保养忘做、样机借出回收
- 金句："少停机就是省钱"；样机管理："谁拿的、去哪了一目了然"
- 预判应答：对方说"我们有WMS/ERP" → "您管的是客户仓库/财务账，我们管的是贵司自己的实物资产，两码事，可API打通"
- 找：行政/财务

### 拟IPO/上市公司（锐石创芯）
- 痛点：**上市审计"账实相符"必查**，Excel台账过不了关
- 金句："账实相符一目了然，审计要什么给什么"；"IPO窗口期就这两年，现在理顺审计才不慌"
- 加分：强调私有化部署、数据不出厂（半导体行业信息安全敏感）
- 预判应答："我们有ERP" → "ERP管财务账，我们管实物——设备在哪个车间、谁在用，补上账实相符最后一环"
- 找：财务（牵头审计）、IR（上市联系人，邮件最有效）
- ⚠️ 别吹"钉钉销量第一"，对芯片厂讲审计合规才专业

### IT/软件/外包（石犀、惟客、艾融、多鲸）
- 痛点：员工流动大、设备借还+离职交接乱、多地办公
- 金句："离职一键查看名下设备，交接不遗漏"；"总部一个后台，全国资产一目了然"
- 预判应答："我们有数据中台/安全平台" → "您管业务数据，我们管实物资产，两码事；私有化部署数据不出厂，符合你们安全标准"
- 找：行政/HR（外包公司设备归行政或人事管）

### 医疗/器械（默尼）
- 痛点：器械耗材效期/批次管理，过期=监管事故
- 金句："效期到期自动提醒，避免过期使用"
- 找：行政/采购

### 渠道型软件/服务公司（博拉、软安、九微）
- 定位：**互推客户+渠道分润**，不是卖给他们
- 话术："咱们都是做B端软件的，客户群高度重叠——您客户里有资产管理需求的推荐给我们，我们有客户需要[安全/营销/呼叫中心]的推荐给您，不抢生意纯加分，给您渠道分润"
- 预判应答："我们专注XX不碰别的" → "不是让您碰，是您客户的额外需求，推荐一下零成本多一笔收入"
- 找：市场部/商务/渠道负责人；跟老板聊同样内容（老板吃"客户资源共享"这套）

### 国企/政企（川铁投广润、视联动力）
- 定位：正式渠道，邮件+约拜访，周期长
- 话术：先邮件（标题带正式感），隔2-3天电话跟进"上周发过邮件想确认收到没"
- 找：行政/综合办；政企大单都是见面谈出来的，电话只是敲门砖

### 小创业/电商/教育（雷电云、淘掌柜、冠岳）
- 定位：价值低，打一遍电话+加微信混脸熟即可，别投入
- 钩子：测试机借还管理（云手机公司）、电脑设备管理
- 目的：加微信是第一目标

## 3. 老板版话术（直接找创始人/法人时）

老板是销售/市场出身的话，吃"客户资源互补"；技术出身的话，聊"数字化管理"。
```
> [称呼]总您好！我是易盘点的小X。知道您[从XX做到XX/服务了哪些大客户]，非常佩服👍
> 咱们都是做B端软件的，客户群高度重叠——[对方行业]单位既需要[对方产品]，也需要固定资产管理。
> ① 互相推荐客户，不抢生意纯加分
> ② 打包进方案，客单价更高
> 我们连续多年蝉联钉钉行政管理类软件销量第一，口碑不错。给您渠道分润，零成本多一笔收入。
> 先加个微信，以后常联系～
```
规则：10秒内说出"客户资源共享"；别提设备盘点；目标=加微信。

## 6. 汇总优先级表格式（多家公司时）

每家用 3-5 行：公司名+地区 → 主业一句话 → 合作点（自身刚需/渠道/客户群）→ 联系方式（电话/邮箱/地址）→ 打法一句话。配 ⭐ 分级：
- ⭐⭐⭐⭐⭐ 重点主攻（客户群优质+可嵌入方案，如博拉）
- ⭐⭐⭐⭐ 渠道/大客户型（国企供应链、数据公司）
- ⭐⭐⭐ 自身需求型（制造厂、硬件厂）
- ⭐⭐ 价值低（电商代运营）
- ⭐ 可跳过（小创业、在线教育）
行动顺序建议放表末（本周攻谁→同步发谁）。
