# 探迹名单批量筛选分级（Batch List Filter & Grade）

> 场景：用户（妈妈）发来探迹导出的 Excel 名单（列：客户名称/法人/电话/经营内容/跟进记录），要求划掉没价值的、按优先级分档。
> 实例：2026-08 处理 200 家初版名单 → 划掉 15 家 → 保留 185 家 → A37/B48/C100。

## 步骤

1. **读文件**：openpyxl 读取（`pip install openpyxl` 若缺）；注意每家公司可能占多行（名称行+空行），`if row[0]` 过滤；可能有多个 Sheet，数据在 Sheet1。
2. **划掉无价值**（规则先行，写进"划掉名单"Sheet 并附理由）：
   - 运营商营业厅/区县分公司：中国移动/联通/电信/广电——网点性质，采购决策在省市公司总部，无 B2B 陌拜价值
   - ⚠️ 正则坑：联通全名是「中国联合网络通信有限公司」，不是「中国联通」，正则必须覆盖 `中国移动|中国联通|中国电信|中国联合网络通信`
   - 个体市场/普通合伙（如「XX工业品市场(普通合伙)」）：规模小非企业客户
3. **分 A/B/C**：
   - A（高价值，优先深挖）：资产密集/央企/上市系/硬件制造/医药流通/IDC 数据中心
   - B（中价值，值得跟进）：中型科技/系统集成/设备类/医疗健康服务
   - C（低价值，暂缓）：游戏/互娱/电商/教育/咨询/外包/传媒/轻资产小微
4. **关键词启发式 + 人工修正**：规则会误判知名公司，必须人工覆盖（本批修正实例）：
   - 海云捷迅→B（云计算服务商，非小微）；大象慧云→B（航天信息系电子发票）；像航→B（无介质全息显示，研发设备）；柯林布瑞→B（医疗大数据）；交运城卡→B（重庆交运国资）；巽诺→B（网络安全/等保）；金穗隆→B（IT分销集成）；导通电子→B（电子工程）；鸿巨网络→B（电脑分销）；云投信息→B（云计算）
   - 医惠大数据/华昭电气/世纪之光/朗德/竞天/澎博财经/吉联/广嘉自动化/美顺电子→A 降 B（区域或软件类，资产中等）
   - 中移(苏州)软件→C（运营商体系，采购封闭）；中国新华新闻电视网→C（国企难进）
5. **写回 Excel**：保留名单 Sheet 新增「分级」「分级理由」两列，另建「划掉名单」Sheet；存 /home/projects/hermes-knowledge/易盘点客户/<名单名>-筛选后.xlsx
6. **汇报 + MEDIA 发回**：给统计（地域/行业分布、划掉数+理由、A/B/C 家数），问下一步（通常是从 A 档逐个深挖）
