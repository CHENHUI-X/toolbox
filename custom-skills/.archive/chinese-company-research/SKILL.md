# Chinese Company Research (企业调研 / 找合作机会)

Use when the user (妈妈/老板) gives a company name and wants: ① 这家公司做啥业务/做哪方面软件 ② 客户/合作生态 ③ 公开联系方式 ④ 跟我们产品(易盘点)的合作切入点 ⑤ 商务合作话术.

## Standard Workflow (in order)

1. **工商概览** — `web_search` 公司全名。企查查(qcc)摘要页直接给出：法定代表人、注册资本、成立时间、曾用名、经营范围(节选)、人员规模、资质标签(高新技术/专精特新/小巨人等)。
2. **深挖 qcc 移动版** — `web_extract https://m.qcc.com/firm/<id>.html`。**关键：手机版页面文本里直接带电话号码**（如 `13833660830 更多1`，数字串会出现在正文中，无需登录）。同时能拿到经营范围全文、股东持股、主要人员(董事/监事名单)、专利、商标、招投标、招聘动态。⚠️ "更多N" = 还有 N 个号码藏在会员墙后。
3. **政府/官媒新闻** — `web_search "公司名" + 客户/合作/案例`，或 site:xxx.gov.cn。政府官网、河北经济日报、长城网等点名：标杆客户（如新疆疆纳集团）、商务口负责人姓名（商务中心经理 潘袆林/周奎志 这类）、在建项目与未来规划（新基地、上市目标）。**这些名字就是联系线索。**
4. **招聘平台补地址/HR** — 猎聘(liepin)、店长直聘(dianzhangzhipin)、职友集(jobui) 公司页给办公地址 + 招聘者/HR 姓名（"段女士 · 咨询师主任"）。
5. **官网 + ICP备案** — 搜 `"公司名" 官网 备案`，用 icp.bugscaner.com 这类备案查询站拿官方域名。⚠️ 官网可能已死：若 `web_extract`/`browser_exec` 报 `Blocked: URL targets a private or internal network address`，说明域名已失效/指向内网，**别反复试，直接换渠道**。
6. **招投标站（工程类）** — cbi360 盯工程等项目站有时给甲方联系人手机号。

## 联系方式获取优先级

1. 企查查移动版正文里的手机号（常是法人/高管私人号，联系时先自报家门）
2. 招聘平台 HR/商务岗联系人（公司在招人 = 活跃，可借 HR 转介绍）
3. 天眼查/企查查 VIP 解锁隐藏号码（"更多N"）
4. 上门：办公/注册地址（注册地址常在园区门牌号，办公地址另见招聘页）

## 合作切入点分析（用户产品要打进去时）

- **对方自身需求**：对方在建厂/扩产/数字化 → 自身就有固定资产管理需求，可做样板。
- **打包进对方方案**：把自家产品作为对方整体方案里的一个模块（渠道分润），他们卖方案时顺带卖我们。
- **客户重叠互补**：对方客户群与自家产品目标客户高度重叠且不冲突（一个管"用"、一个管"账"）→ 渠道互补。

## Output Shape

基本盘(成立/法人/资本/资质) → 主营业务 → 软件/产品方向 → 客户与生态 → 联系方式(号码/地址/官网及状态) → 合作切入点建议 → (如需要)商务话术。

## Pitfalls

- **政府公示名单上的电话是公示单位的，不是公司的！**（如质量奖公示留的 0316-2338629 是政府电话）引用前必须确认归属。
- 曾用名常是另一写法（珍圭谷 vs 珍珪谷 教育科技），ICP备案/官网域名可能挂在曾用名主体下，搜索时两个写法都试。
- 公开手机号多为法人私人号，用于商务联系要礼貌自报身份，别当公司座机用。
- 找不到座机/邮箱很正常（很多公司不公开），如实告知 + 给替代路径，不要编造。
