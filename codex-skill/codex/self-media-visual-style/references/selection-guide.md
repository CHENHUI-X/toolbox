# 内容与视觉匹配示例

这是如何判断的示例，不能固化为主题到编号的映射。先服从用户当前指定的方向，再依据正文决定具体条目。

## 人物叙事与机制解释

| 文案需要 | 选择重点 | 画面如何承担信息 |
|---|---|---|
| 家庭、教育、关系、情绪 | 人物表情、身体姿态、亲疏距离、日常空间 | 同一孩子面对不同成人回应，呈现行动和情绪的变化 |
| 职场、沟通、认知偏差 | 对话关系、信息差、具体任务、轻喜剧节奏 | 同一张表格，从只说术语到把第一步示范出来 |
| 科学、科技、结构与流程 | 结构可读、因果过程、尺度关系、真实限定 | 关键物件有可解释的变化；人物可以导览，不遮挡原理 |
| 社会争议、热点 | 对照、条件、证据与角色视角 | 保留语境，不用敌我颜色或夸张恶人表情代替论证 |
| 历史、成语、文化 | 时代环境、叙事顺序、道具与人物动作 | 动作讲清事件，不把古风装饰当故事内容 |

## 2026-10-10：这两条改用手绘线条

用户在比较动画方向后指定“用那种手绘线条风格”。这次优先用手绘人物叙事，保留完整场景和精致表演，不采用此前被否定的写实水粉角色图。

**“吃苦教育”**：首选 `handraw:FA-034`，Elastic Sunday Strip。重点是有弹性的墨线、孩子的夸张但可信的表情、明确肢体动作，以及少量透明色块。原条目对应 Bill Watterson，但创作原创中国孩子与家长，不复制既有角色、服装或故事。家庭书桌、鞋带、孩子攥手和成人蹲下回应可以形成真实叙事。`awesome:533` 可补充线条与少量上色组织；不能照搬它的点眼睛、统一笑脸和空白背景设定。

**“越懂越讲不清”**：首选 `handraw:FA-013`，Bold Flat Everyday Satire。用醒目墨线、有限色块和成年人日常轻喜剧，表现讲者兴奋、听者迷茫以及示范后理解的变化。这里的粗轮廓要保留手绘笔压，不能做成规整矢量图标。`awesome:513` 可参考线条与单点色控制，替换旅行地标为办公室任务；不把旅游手账当最终画面。若它与教育片需要批次统一，可以沿用 FA-034 的墨线特征来画成年角色。

**跨镜头组织**：`awesome:419` 只参考“同一人物、每个镜头一种具体动作、全景与手部特写交替”的组织方法，不采用该例的 3D 材质、面包师或烘焙剧情。`awesome:372` 只参考表情与全身姿态设定的组织方式，不照搬其日系少女比例与服饰。角色表不是成片；生图给出静态关键帧后，仍须制作真实动作。

## 可执行提示词骨架

“原创手绘线条二维动画关键帧，墨线随笔压变化，轮廓略有不规则但清楚，少量【具体颜色】色块，轻微自然纸感而非做旧纸。角色为【年龄、头身比例、固定发型衣着】，在【具体完整场景】执行【与该句文案对应的动作】。表情从【起始状态】到【结果状态】，身体姿态和人物距离表现【需要传递的关系】。镜头为【景别与视角】，画面保留【字幕或标题位置】。不画现成知名角色、不做空白背景头像、不替换成火柴人或规整矢量图标。”

动画提示词另外写清动作起止、接触对象、节奏、表情转折、固定镜头或运镜，以及与前后镜的连续关系。科学机制、字幕和数据按正文与真实来源绘制，不让模型自行补充结论。
