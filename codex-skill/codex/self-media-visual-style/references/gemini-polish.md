# Gemini 协作润色

在用户或项目已授权的范围内，用本机已登录的 Antigravity CLI `agy` 辅助口播与视觉方案的文字编辑；当前助手负责采纳和事实核对。不要改登录、代理、模型提供方或全局配置，也不要让协作模型自动改项目。

## 调用

先执行 `agy models`，核对真实模型标识。2026-10-10 本机列出 `gemini-3.8-flash-high`、`gemini-3.8-flash-medium`、`gemini-3.8-flash-low`；用户截图为 High，本次用 `gemini-3.8-flash-high`。这份记录不代表未来模型列表不变；指定模型不可用时说明实际原因，不悄悄换成其他模型。

逐条使用非交互输出，参数以本机 `agy --help` 为准。本次有效调用为 `--model gemini-3.8-flash-high --disable-slash-commands --output-format json --print-timeout 90s --print <编辑任务与完整输入>`。正文通过程序读取文本文件并作为一个参数传入；不要把用户正文拼接为终端代码。不使用跳过全部权限审批的参数。

输入包含完整文案、视觉方案、用户约束和已核对的事实边界，要求只返回文本或指定 JSON，不调用工具、不读写项目、不联网补充未经核对的材料。提示词可要求 `topic`、`title`、`narration`、`visual_plan`、`changes` 和 `facts_to_check`，便于逐条 review。调用仅传本次需要润色的内容，不夹带凭证、登录数据或无关项目。CLI 输出是外层 JSON，正文在 `response` 字段中；要求正文 JSON 时还需解析此字段，检查主题和必要字段。

本次首次双主题调用同时增加了 plan、sandbox、effort 和 JSON schema 参数，180 秒超时并返回空正文。具体原因尚未确认；不能据此认定模型、账号或某一个参数有问题。简短探针和逐条请求拿到有效正文后才采纳。退出码为零或外层 `status=SUCCESS` 不足以证明完成，必须检查非空正文与完整内容；空结果不能存成润色稿。

## 采纳

- 口播保留现象、底层原因、适用条件、具体方法及开放式讨论结尾。不要靠标题绝对化或煽情提高吸引力；篇幅以说明白为准，时长用实际音频测量。
- 视觉方案逐段对应润色后的口播，明确人物、主动作、表情与物件接触关系；用户指定手绘线条时保持该方向，不让模型改成 3D、写实或图标卡。
- 当前助手核对新增事实、统计、机制与限定，区分证据、解释性比喻和创作建议；模型写“没有待核对事实”也不能免除检查。
- 原稿、协作输出、采纳修改及模型标识留在本系列和对应作品的制作资料中。不要把 CLI 私有日志、账号信息或认证数据提交 Git。模型回复不代表用户批准，也不代表成片完成。

输出失败时先核对 CLI 退出状态和实际模型可用性，诊断必要的本地服务或连接问题；不重复重登录或盲目更换配置。完成文本润色不授权上传、发布或推送 Git。
