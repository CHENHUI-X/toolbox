# 自媒体视觉选风格

用两个参考库形成具体、可追溯的视觉方案。先理解内容，再挑风格；同一作品统一视觉语言，不把所有主题套成旧纸科普卡或固定画风。

## 按内容挑选

- 先读完整文案和项目 `AGENTS.md`，明确核心问题、受众、情绪、具体场景，以及画面主要承担叙事、对照还是机制解释。用户已经指定的风格优先；不要为了“推荐”改掉它。
- `handraw-style` 主要提供线条、人物比例、媒介和视觉人格；`awesome-gpt-image-2` 提供实际案例，以及角色表情、构图、场景和分镜组织参考。可组合“一个主画风＋一个构图/角色组织参考”，不混合多个互相冲突的渲染风格。
- 用 [catalog.py](scripts/catalog.py) 搜索本地索引，只读取候选条目。搜索是关键词检索，最终按文案判断，不能把检索顺序当作推荐结论。

```bash
python3 <技能目录>/scripts/catalog.py search 手绘 墨线 儿童 --source handraw --limit 6
python3 <技能目录>/scripts/catalog.py search 手绘 分镜 表情 --source awesome --limit 6
python3 <技能目录>/scripts/catalog.py show handraw:FA-034
python3 <技能目录>/scripts/catalog.py show awesome:533 --full
```

- 定选前查看候选原图，并核对具体提示词。仓库标题、标签、模板示例与内容可能不一致；数字编号只作索引，不能凭记忆套编号，也不把仓库名视为模型效果保证。图片无法查看时，明确本次仅有文字依据。
- 未指定画风时，给一个明确首选及简短理由；只有存在有意义的差别时才提供备选。用户已指定方向时，在该方向内选具体条目，直接继续已授权制作。

## 从风格变成画面

将来源条目翻译为明确特征：线条粗细与笔压、头身比例、五官和表情、材质、色彩、场景、光影与镜头。作者名只作来源标识，提示词使用这些视觉特征。原案例的年龄、性别、服装、角色、文字和背景并非必须照搬。

建立“文案段落 → 具体人物/物件 → 动作或变化 → 帮观众理解什么”的分镜关系。家庭教育必须看得见孩子及其反应；沟通题要看得见说话者、听者和具体任务。角色不是概念图标，精致也不等于堆装饰。机制图解保留真实结构和条件，隐喻不要冒充医学、技术或统计事实。

视频画风选择须考虑实际可动画性：动作拆分、轮廓清楚、表情变化、角色连续性、道具接触和场景空间。角色动画要有有意义的姿态与表情变化；只给静态插画加推拉、漂移和字幕，不能作为用户要求的动画片交付。新方向先做短动态样片检查，再扩展全片；用户要求看样片时交给用户 review，未要求时可自行检查后继续。

手绘线条方向优先保留真实笔压、不完全规整的轮廓、清楚的动作剪影和有限配色；避免退化成火柴人、统一呆笑、空白背景加大字。详见 [选择与制作示例](references/selection-guide.md)，其中示例是内容判断的演示，不是固定主题与编号映射。

## 可选协作润色

项目或用户授权使用本地 Gemini 时，可让已登录的 `agy` 润色口播和视觉方案。先确认实际可用模型，使用指定的 Gemini 3.8 Flash；只传入这次需要编辑的正文、分镜和核实过的事实边界，要求纯文本/结构化输出，不让它改项目或调用其他工具。操作方法见 [Gemini 协作润色](references/gemini-polish.md)。润色后由当前助手核对新增事实、因果限定和文案与动作对应，保留初稿、模型输出及最终采纳稿；模型的自评不能代替验收。

## 制作与归档

- 使用当次可用的生图和动画工具；参考库不限定生成模型，也不要求购买第三方服务。图片生成或编辑沿用适用的 imagegen 技能，动画制作沿用实际可用的制作流程。
- 一条作品保持角色身份、衣着、线条、材质和主配色一致；跨作品可以按题材重新选。封面取自真实内容，独立 4:3 横向构图，避免只裁切竖帧。
- 在对应作品的 `工程/视觉方案.md` 记录主风格、案例用途、选择理由、来源编号和链接、源版本、角色/场景设定、分镜与完整提示词。按项目规则保留文案、配音、视频、封面和验收；选风格不代表作品已生成或发布。
