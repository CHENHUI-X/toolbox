# 中国企业信息批量补全方法论

## 用户工作模式
- 每天给一批**新**公司名单(数量不定, 10~50家/天), 要求补全 法人/联系方式/注册地址/存续状态/是否异常及原因
- 每日名单独立处理, 当天跑完交付规范Excel; 跑不完的进"待补清单"次日用赠送积分续
- 本skill沉淀的是**方法论**: 从哪获取、怎么获取、怎么处理

## 字段分级(硬约束)
| 字段 | 来源要求 |
|---|---|
| 法人、法人联系方式(工商登记电话)、存续状态 | **必须权威源**(企查查MCP, 备选天眼查) |
| 其他补充联系方式(招聘/官网电话) | 网络搜索(百度PC/搜狗微信) |
| 注册地址、是否异常及原因 | 企查查MCP权威; 异常"确认无异常"只能权威源给出 |
| 经营内容 | **必须留空** |

## 数据获取渠道矩阵(2026-08实测)
| 渠道 | 用途 | 状态/代价 |
|---|---|---|
| **企查查MCP** agent.qcc.com | 权威三项+地址+异常 | ✅唯一实测可用权威源; 每日送100积分≈11家/天; 单家完整≈9积分 |
| 天眼查开放平台 | 权威备选 | ⚠️"免费每日500次"仅SEO软文, 未实测; open.tianyancha.com访问受限 |
| 百度PC Playwright (Hermes skill) | 补充联系方式/参考法人状态 | ✅免费; 2026-08-05法人命中率已降至~42%, 只作参考 |
| 搜狗微信文章搜索 | 教育机构电话金矿 | ✅免费无验证码; 摘要含招聘电话/白名单地址 |
| 头条/神马浏览器通道 | 兜底 | ✅免费; 字节/阿里独立风控池可并行 |
| gsxt国家企业信用信息公示系统 | 免费官方权威 | ❌HTTP 521加速乐+极验, 不可批量 |
| 省级公共数据开放平台 | 免费官方 | ⚠️按省覆盖有限(北京27家), 需注册 |
| 免费代理池/住宅代理 | 换IP | ❌免费池实测无用; 数据中心IP被风控更狠 |

## 决策流程(每天新数据)
1. 读名单Excel → `extract_names.py` 提取公司名列表(自动识别公司名列)
2. 规模判断: 若 ≤11家, 直接企查查MCP跑完(当日100积分足够); 若 >11家, 先跑11家权威, 其余进待补
3. 权威字段: `qcc_mcp_batch.py` 跑(积分够的全量, 不够的进待补); 次日 `qcc_mcp_topup.py` 续补
4. 补充联系方式: 百度PC/搜狗微信跑(免费不限量), 只补电话/地址
5. 合并: `merge_deliver.py` → 规范Excel; 权威字段以MCP为准, 浏览器法人/状态标"参考"
6. 交付: 列顺序 公司名称|法人|联系方式|注册地址|经营内容(空)|是否异常|异常原因; 附"数据来源"说明列

## 企查查MCP要点
- 密钥: `~/Desktop/yy工作/密钥` (JSON, mcpServers结构, Bearer <key>)
- 端点: `https://agent.qcc.com/mcp/{company|risk|...}/stream`, Header `Authorization: Bearer <key>`
- 工具: `get_company_registration_info`(法人/状态/地址/信用代码) + `get_contact_info`(工商电话, 标签如"疑似代记账") + `get_business_exception`(异常权威结论)
- 积分: 单家完整3次调用≈9积分; 注册500积分≈56家; 每日100积分≈11家
- 错误码: 300008=积分不足(当日停, 次日续); 200001=鉴权错; -32001=日频率超限
- 异常解析: 取返回"经营异常信息"[0]的"列入日期"+"列入经营异常名录原因"; "未发现任何经营异常记录"→否
- MCP配置后需重启Codex才加载工具; 不重启可用脚本直连HTTP端点(不依赖工具加载)

## 数据处理规范
- 电话清洗: 排除邮箱/@、网址、脱敏(****)、<7位; 企查查电话保留标签(如"疑似代记账"可标注); 区号+省市联动过滤噪声
- 法人交叉验证: 多源不一致时标注存疑(参考Hermes skill的法人冲突清单), 以企查查为准
- 分公司: 负责人字段(非"法定代表人")按企查查返回
- 异常: "确认无异常"只能权威源给; 浏览器未检出≠无异常, 留空待补

## 工作区目录规范 (~/Desktop/yy工作)
- 每天一个批次文件夹 `2026-08-XX/`, 用户把名单Excel直接放进该文件夹(无需建子目录)
- 脚本产出: 当天文件夹下自动建 `数据/`(中间JSON) 和 `结果/`(交付Excel)
- 共享位置: `密钥`在顶层 `~/Desktop/yy工作/密钥`; 通用脚本在 `~/Desktop/yy工作/脚本/`; 历史批次在 `2026-08-01/`(保留), 调研临时文件在 `归档/`(只读)
- 每次新批次: extract_names.py 提取名单 -> qcc_mcp_batch.py 跑权威 -> 不足进待补 -> 浏览器补联系方式 -> merge_deliver.py 交付

## 脚本(均在 scripts/)
- `extract_names.py` <xlsx> [列名关键词] : 提取公司名→stdout/文件, 自动识别"公司名称/企业名称"列
- `qcc_mcp_batch.py` <名单.txt> <起> <止> [输出.json] : 企查查MCP批量(工商+联系+异常), 每10家落盘
- `qcc_mcp_topup.py` [预算积分=100] [累计json] : 续补待清单位(自动跳过已完成, 300008自动停)
- `merge_deliver.py` <qcc.json> [baidu.json] <输出.xlsx> : 合并生成规范Excel, 权威优先
- 浏览器通道脚本: 复用Hermes skill /Users/didi/.hermes/skills/research/cn-company-batch-enrichment/scripts/baidu_pc_pw.py
