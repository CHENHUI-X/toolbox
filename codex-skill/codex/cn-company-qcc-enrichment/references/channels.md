# 数据源实测矩阵 (2026-08-05 实测)

## 企查查 MCP (agent.qcc.com) — 唯一实测可用权威源
- 免费额度: 注册500积分(30天) + 每日100积分(普通用户, 当日有效); VIP 150/天, SVIP 200/天
- 认证奖励: 企业实名认证 +200积分(90天); 邀请好友每激活1人+100(每月最多5人)
- 充值: 1元=10积分 (用户约束: 不充值)
- 单家完整查询(工商+联系+异常): ≈9积分; 100积分≈11家/天
- 同实体月度积分封顶: 企业100积分/月, 个体工商户20积分/月(持续监控场景才受益)
- 工具: company server 16个(get_company_registration_info/get_contact_info/get_annual_reports等), risk server 38个(get_business_exception等)
- 门槛: 手机号注册即可, 无需企业认证(history server才需认证); 开放平台openapi.qcc.com才需企业实名
- 实测: 184家批量约6分钟(积分充足时); 法人/状态/电话/异常全字段命中

## 浏览器搜索通道 (免费, 作参考/补联系方式)
- 百度PC www.baidu.com: Playwright, ~18s/家, 2026-08-05法人命中率降至~42%(风控加强), 电话命中率仍可用
- 搜狗微信 weixin.sogou.com: 教育机构电话金矿, 摘要含招聘电话/白名单地址, 无验证码
- 头条 m.toutiao.com / 神马 m.sm.cn: 字节/阿里独立风控池, 可并行; 法人污染需全称锚定
- 教训: 同池勿并行(百度3路必封); 每10家落盘防进程被杀

## 官方免费源 (受限)
- gsxt.gov.cn: HTTP 521 加速乐JS challenge + 极验, 不可批量; 单IP 300请求/小时封禁
- 省级开放平台: 北京data.beijing.gov.cn有工商全量文件下载API(需注册key, 覆盖北京市); 山东data.sd.gov.cn有工商查询API
- 信用中国/统一社会信用代码平台: 免费但无批量API, 无电话
